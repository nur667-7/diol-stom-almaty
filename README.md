## 💡 О проекте

Сайт разработан как премиальная альтернатива устаревшим шаблонным решениям. Главная цель — дать пациентам клиники максимальную прозрачность, доверие к экспертной команде врачей и мгновенное удобство записи на прием с мобильных и десктопных устройств.

### ✨ Ключевые преимущества и стек
- **Дизайн по брендбуку клиники:** Фирменный глубокий синий (`#27348b`) и акцентный красный (`#ea2127`) из официального логотипа.
- **Отказ от одностраничной перегрузки:** Полноценная модульная многостраничная архитектура, оптимизированная под SEO и конверсию.
- **Мобильный приоритет (Mobile-First):**
  - Интуитивное боковое меню с быстрым доступом.
  - Нижний фиксированный бар (Bottom Navigation Bar) для записи в 1 клик, звонка и перехода в WhatsApp.
  - Оптимизированные touch-зоны для смартфонов.
- **Интеграция с Kaspi:** Встроенный умный калькулятор рассрочки (0-0-12 и 0-0-24) для комфортного планирования бюджета на имплантацию и брекеты.
- **Аутентичный контент клиники:**
  - Реальные фотографии интерьеров и кабинетов в слайдере.
  - 12 сертифицированных докторов клиники с реальными квалификациями (стаж до 45 лет).
  - 70+ актуальных цен из утвержденного прайс-листа с живым поиском и фильтрацией по категориям.
  - Премиальное оборудование: томограф 3D КТ Morita Accuitomo (Япония) и стоматологические установки KaVo (Германия).

## 🛠 Технический стек

- **HTML5 & Modern Semantics**
- **Tailwind CSS (JIT)** — утилитарная адаптивная стилизация.
- **Alpine.js** — реактивное состояние (калькулятор, поиск по прайсу, модальные окна, мобильный drawer).
- **Lucide Icons** — чистые векторные иконки.
- **Wrangler / Cloudflare Workers** — сверхбыстрая доставка статики с кэшированием на Edge-серверах по всему миру.

## 🚀 Запуск и развертывание

### 1. Локальный запуск
Так как сайт построен на современной статической архитектуре, для запуска достаточно любого локального веб-сервера:

```bash
# С помощью Python:
python -m http.server 8000 --directory site

# Или с помощью Node.js:
npx serve site
```
Откройте браузер по адресу: `http://localhost:8000`

### 2. Деплой на Cloudflare
```bash
npx wrangler deploy --name diol-stom-almaty site
```
